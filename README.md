
# Open Anywhere

**Open Anywhere** is a Minecraft Forge mod designed to make inventory management more convenient while maintaining a vanilla-friendly experience.

Instead of having to place down physical blocks such as shulker boxes, crafting tables, ender chests, etc., to interact with them, you can open their respective GUIs by hovering over the items and pressing a hotkey.

## Features

- **Portable Crafting** — Access crafting tables directly from your inventory.
- **Portable Workstations** — Use supported workstations without placing them down.
- **Shulker Box Access** — Open and manage shulker boxes directly from your inventory.
- **Ender Chest Support** — Access shulker boxes stored inside your ender chest. Auto-return to ender chest on close.
- **Vanilla-Friendly** — Uses Minecraft's existing interfaces to preserve the vanilla experience.
- **Configurable Keybind** — Customize the key used to open supported items.

**Note:** GUIs opened by *Open Anywhere* will not close if the player moves away from their original location (e.g., while traveling with an Elytra).

### Supported Blocks

- Shulker Boxes
- Ender Chest
- Crafting Table
- Stonecutter
- Loom
- Cartography Table
- Anvil
- Enchanting Table
- Grindstone


## How to Use

1. Open your inventory or a supported container.
2. Hover your cursor over a supported item.
3. Press **R** (default keybind).
4. The item's interface will open automatically.

The keybind can be changed through Minecraft's Controls settings.

For shulker boxes/ender chests, any changes to their contents are saved back to the original item when the interface is closed.

## Compatibility

| | |
|---|---|
| Minecraft Version | 1.20.1 |
| Mod Loader | Forge |
| Client/Server | Both required |

**Note:** Open Anywhere requires installation on both the client and server when playing multiplayer.
